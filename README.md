# Pocket Ripple — No Tile Left legal resources

Approved public Privacy Policy and email account-deletion instructions only. No game source, backend, database, SDK, credentials, analytics or account API is included.

## Free GitHub Pages publication

Use a dedicated public repository. Upload exactly these files, including the empty .nojekyll file. In Settings → Pages, select Deploy from a branch, main, /(root). Enable Enforce HTTPS when available. Wait for the successful Pages deployment and use the exact URL returned by GitHub; no username or domain is assumed here. Verify privacy/ and delete-account/ while signed out before replacing any existing links.

Navigation is relative and styles are embedded: both a repository project path and a future custom-domain root work without rebuilding. No external font/image/script is needed.

## Future custom domain

No domain is configured or purchased. When the owner supplies a domain they control, verify ownership in GitHub, follow GitHub Pages DNS instructions, set the verified custom domain in Pages, and enforce HTTPS after certificate provisioning. Do not add a guessed CNAME. Recheck both legal URLs and update the game's canonical runtime settings and Android fallback together. Keep the previous working URLs during transitions.

## Content updates

Canonical publisher fields and policy wording remain in the private game source. Re-export with npm run legal:github -- /absolute/empty/output-directory and review the five-file allowlist before committing an update here. The policy distinguishes GitHub legal-page hosting from the game's other services. Email initiation does not mean automatic account deletion or verified mail delivery.
